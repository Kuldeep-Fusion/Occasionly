# Occasionly 👑✨

A royal, interactive digital wedding & event invitation web application built with **Next.js (App Router)**, **React 19**, **Framer Motion**, and **Vanilla CSS**. 

Experience the timeless elegance of traditional Indian weddings reimagined as a modern, interactive digital invitation card.

---

## 🌟 Key Highlights & Features

### 1. 💌 3D Royal Wax-Sealed Envelope Entrance
- **Interactive Wax-Seal Tap-to-Open**: Guests are greeted by a wax-sealed royal envelope modal.
- **Sound on Tap**: Plays the authentic festive wedding soundtrack (`sahil-anjali-soundtrack.m4a`) as the envelope unfolds.
- **Golden Rose Petal Shower & Confetti Blast**: Festive celebratory burst using `canvas-confetti` upon entrance.

### 2. 🏛️ Fixed Royal Palace Backdrop & Scrolling Canvas
- **Immersive Architectural Frame**: Fixed royal wedding palace background featuring ornate marble pillars and golden floral arches.
- **Smooth Center-Aligned Scrolling**: All ceremony details, countdowns, and venue directions scroll seamlessly over the fixed royal frame.
- **Subtle Falling Rose Petals**: Delicate floating rose petals drifting gently in the background.

### 3. 🕉️ Sacred Shlokas & Auspicious Blessings
- Lord Ganesha illustration with the sacred Sanskrit Shloka:
  ```
  ॥ वक्रतुण्ड महाकाय सूर्यकोटि समप्रभ।
  निर्विघ्नं कुरु मे देव सर्वकार्येषु सर्वदा॥
  ```
- `#SaAnj` royal monogram in crimson maroon and antique gold.
- Authentic royal fonts: *Berkshire Swash*, *Great Vibes*, *Alex Brush*, *Kalam*, and *Cinzel*.

### 4. ⏳ Real-Time Countdown Timer
- Live countdown clock counting down the days, hours, minutes, and seconds until the auspicious wedding day (**12th November 2026 at 11:30 AM**).

### 5. 🌸 Detailed Ceremony Itinerary
Complete function guide with traditional artwork and dress codes:
- 💛 **Haldi**: *12th Nov 2026 | 11:30 AM onwards* — *Attire: Shades of Yellow*
- 💃 **Sagai & Sangeet**: *12th Nov 2026 | 5:00 PM onwards* — *Attire: Western Glamour*
- 🎺 **Baarat**: *13th Nov 2026 | 10:30 AM onwards* — *Attire: Traditional Indian Elegance*
- 🍽️ **Royal Lunch**: *13th Nov 2026 | 1:30 PM onwards* — *Festive Feast*
- 🔥 **Phere**: *13th Nov 2026 | 5:00 PM onwards* — *Sacred Seven Vows*

### 6. 📍 Venue & One-Click Navigation
- **Destination**: *Omnia by Tivoli*, Sector-2, Greater Noida West.
- **One-Click CTA**: Direct link to open Google Maps navigation and directions on mobile or desktop.
- Interactive venue card with hand-crafted illustrations.

### 7. 🎬 Motion Portrait Reception Video
- Framed in a handcrafted 20px golden baroque border with soft ambient glow.
- Responsive, seamless looping HD video (`video.mp4`) with instant fallback poster.

### 8. 🎵 Ambient Music Controller
- Floating golden audio disk with rotation animation, play/pause controls, and volume state.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Library**: [React 19](https://react.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: Vanilla CSS / Styled-JSX with CSS variables
- **Confetti**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Database (Optional / API ready)**: [MongoDB](https://www.mongodb.com/) via Mongoose

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.18.0 or newer recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Kuldeep-Fusion/Occasionly.git
   cd Occasionly
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run local development server**:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the invitation.

---

## 📦 Production Build

To test and build the production-ready bundle:

```bash
npm run build
npm run start
```

---

## 🌐 Deployment

### Deploying to Vercel (Recommended)
1. Push your repository to GitHub.
2. Sign in to [Vercel](https://vercel.com).
3. Import the `Occasionly` repository.
4. Keep the default Next.js build settings and click **Deploy**.
